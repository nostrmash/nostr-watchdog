# Security

See [docs/security.md](docs/security.md) for the threat model of this branch.

Report a vulnerability privately to the maintainers of [nostrmash/nostr-watchdog](https://github.com/nostrmash/nostr-watchdog) before opening a public issue. Do not include sender keys, operator tokens, or production alert text in the report.

This branch is not the production deployment. The production TypeScript Worker remains on `main`.
